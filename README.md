# Offline Medical Office

**Offline Medical Office** — إدارة مكتب طبي تعمل دون اتصال بالإنترنت (offline-first medical office management for Windows).

- **Stack:** Electron + Node.js + SQLite (better-sqlite3)
- **Methodology:** Specification-First — no code before design approval
- **Status:** Foundation phase
