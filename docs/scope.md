# نطاق التطبيق — Offline Medical Office

## الغرض

تطبيق Windows مكتبي لإدارة مكتب طبي محدود، يعمل دون إنترنت.

يدير دورة حياة زيارة المريض: من الدخول إلى الفاتورة إلى تقرير الخروج.

## المستخدم

- **موظف استقبال (Receptionist):** يُدخل المرضى، يفتح الزيارات، يضيف الإجراءات، يُخرج المرضى.

- **مسؤول النظام (Admin):** يدير الكتالوجات، الإعدادات، النسخ الاحتياطي.

لا يوجد نظام تسجيل دخول متعدد الصلاحيات في المرحلة الأولى.

## داخل النطاق (5 وحدات)

### 1. تسجيل المريض والدخول

- بيانات المريض: رقم الملف (ثابت)، رقم الحالة (لكل زيارة)، الاسم، هاتف الطوارئ، اسم المرافق، صلة القرابة.

- حالة الدخول: مستقرة / حرجة / طارئة / تحت الملاحظة.

- نوع العقد: خاص / تأمين.

- الجهة المحوّلة: من كتالوج قابل للإدارة.

### 2. الكتالوجات

- إدارة الجهات المحوّلة (مستشفيات).

- إدارة الإجراءات (علاج، تحاليل، أشعة، إسعاف).

- إضافة / تعديل / تعطيل. لا حذف فعلي. السجلات التاريخية محفوظة.

### 3. الفواتير متعددة البنود

- اختيار عدة إجراءات في الزيارة الواحدة.

- حساب آلي: (سعر الوحدة × الكمية) = إجمالي البند.

- حساب آلي للإجمالي الكلي عند الإضافة أو الحذف.

### 4. الخروج وحساب الأيام

- عند إدخال تاريخ الخروج، يُحسب عدد الأيام تلقائيًا (بحد أدنى يوم واحد).

- حساب حصة المريض وحصة التأمين حسب نوع العقد.

### 5. تقرير الخروج

- ملخص مالي: الأيام، الإجمالي، حصة المريض، حصة التأمين.

- ملخص سريري بسيط.

## خارج النطاق

- لا يعمل عبر الإنترنت أو مزامنة سحابية.

- لا يدير المخزون الدوائي.

- لا يدير المواعيد أو جدولة الأطباء.

- لا يحتوي سجلات طبية تفصيلية (تشخيص، وصفات، نتائج تحاليل).

- لا يدعم الطباعة الحرارية أو الفواتير الإلكترونية الضريبية.

- لا يدعم تعدد المستخدمين أو الصلاحيات المتقدمة.

- لا يدعم منصات غير Windows.

## معايير النجاح

- إدخال زيارة كاملة وحساب إجماليها دون تدخل يدوي.

- إخراج المريض وإصدار تقرير خروج صحيح.

- العمل دون إنترنت دون أي خطأ.

- نسخة احتياطية قابلة للاستعادة.

- تثبيت نظيف على Windows دون Node.js.

## أسئلة مفتوحة تُعطّل التصميم

- **OQ-001:** معنى "تأمين شامل" ماليًا — هل المريض يدفع 0%، أم هناك حصة رمزية تُدار داخليًا؟

- **OQ-002:** هل "خاص" يعني المريض 100%؟

- **OQ-003:** شركة التأمين: كتالوج مستقل أم حقل نصي حر؟

- **OQ-004:** هل رقم الحالة فريد عالميًا أم لكل مريض؟

## خارج نطاق هذا المستند

- تصميم قاعدة البيانات → مستند لاحق.

- القرارات المعمارية → مستند لاحق.

- تصميم الترخيص والنسخ الاحتياطي → مستند لاحق.
